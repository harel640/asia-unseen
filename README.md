# Asia Unseen

Homepage and privacy policy for **Asia Unseen**, a short-form video channel about
lesser-known travel destinations in Asia. Served via GitHub Pages.

- Home: `index.html`
- Privacy policy: `privacy.html`

This is a static, public site. It contains **no secrets** and collects **no user data**.
The channel's publishing tool uses the YouTube Data API only to upload videos to its own
channel; see the privacy policy for details.
